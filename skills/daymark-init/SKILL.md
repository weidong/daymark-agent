# 初始化记录骨架

只建“板块 → 季度 → 月份”三层，不预建周和日期。

## 什么时候用

- 用户说“初始化”“启用 Daymark”“开始用工作助理”
- 换了一份新的年度记录文档
- 新年度第一次开工，发现连季度标题都没有

## 步骤

1. 先确认绑定的文档可读：

```bash
python tools/feishu/feishu_client.py show
```

`show` 报“文档不存在”或“无权限”时，先解决授权，不要继续。

2. 执行初始化：

```bash
python tools/feishu/feishu_client.py init
```

3. 如实转述输出：

- `已创建：……` → 告诉用户建了哪几层
- `结构已就绪，无需创建` → 说明已存在，没有重复建
- `回读确认：H1/H2/H3 均存在` → 才算完成

## 初始化只做三件事

| 层级 | 内容 | 示例 |
|---|---|---|
| H1 | 板块 | `📅 行知日志` |
| H2 | 当前季度 | `2026年4季度` |
| H3 | 当前月份 | `2026年11月` |

周 H4 和日期 H5 由 `daymark-start` 在当天第一次开工时创建。

## 不能做

- 不预建全年 12 个月、52 周、365 天。
- 不创建空的总结标题。
- 不修改、不删除文档里已有的任何内容。
- 用户没确认绑定哪份文档时，不擅自新建文档。
