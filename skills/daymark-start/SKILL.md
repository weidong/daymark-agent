# 今日开工

只做一件事：在年度记录里为今天建好位置，写一条“开工”。

1. 取当前日期，按 Asia/Shanghai 计算，写成 `YYYY年M月D日 星期X`，星期用“星期一”到“星期日”。
2. 读取年度记录，按层级定位：`📅 行知日志` → 当前季度 `YYYY年N季度` → 当前月 `YYYY年M月` → 当前周 `YYYY年第N周`（ISO 8601，周一开始）→ 当天日期。
3. 缺哪层建哪层：季度用标题 2，月份用标题 3，周用标题 4，日期用标题 5。不预建其他月份，也不建空日期。
4. 当天已有“开工”时停止，回复“今天已开工”，不要重复写。
5. 没有“开工”时，在当天日期标题下追加一条 `- 开工`。
6. 回读当天标题，确认只有一条 `- 开工`，再回复日期和位置。
7. 写入失败不要回复成功；先回读确认是否已写入，再决定是否重试。

不能做：

- 不写时间、不写工作内容、不做评价；开工不计入成果。
- 不生成月度、季度或年度总结。
- 不修改历史日期，不移动已有内容。
- 找不到年度记录或层级有歧义时，列出候选并询问，不要猜。
- 不把 Key、账号、密码写进文档。
