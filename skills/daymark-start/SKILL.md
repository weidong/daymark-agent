# 今日开工

只做一件事：在年度记录里为今天建好位置，写一条“开工”。

## 执行

在项目根目录运行：

```bash
python tools/feishu/feishu_client.py today
```

补记某一天时加参数：

```bash
python tools/feishu/feishu_client.py today --date 2026-11-15
```

## 判断结果

- 输出包含 `已写入开工`：成功，回复日期和当前条目。
- 输出包含 `已有开工，跳过`：今天已开工，不要重复写，直接回复“今天已开工”。
- 输出包含 `未找到「📅 行知日志」板块`、`读取块失败`、`刷新用户令牌失败`：失败，原样说明原因，不要回复成功。
- 报 `tokens.json` 不存在或授权失效：提示先运行 `python tools/feishu/login.py` 完成授权。

## 规则

1. 日期按 Asia/Shanghai 计算，写成 `YYYY年M月D日 星期X`，星期用“星期一”到“星期日”。
2. 层级固定为：`📅 行知日志` → 季度（标题 2）→ 月（标题 3）→ 周（标题 4，ISO 8601）→ 日期（标题 5）。
3. 工具自动补齐缺失层级，不预建其他月份，也不建空日期。
4. 写入后必须回读当天标题，确认只有一条 `- 开工`，再回复。
5. 失败不要回复成功；先看命令输出里的错误，再决定是否重试。

不能做：

- 不写时间、不写工作内容、不做评价；开工不计入成果。
- 不生成月度、季度或年度总结。
- 不修改历史日期，不移动已有内容。
- 找不到年度记录或层级有歧义时，列出候选并询问，不要猜。
- 不把 Key、账号、密码写进文档。
