# 月度复盘

把当月零散记录归纳成四类速览，写成草稿放在 `YYYY年M月速览` 下。

## 执行

1. 读取当月记录：

```bash
python tools/feishu/feishu_client.py month --month 2026-11 --json
```

2. 如果 `total_items` 为 0，直接回复“本月暂无工作记录，无法生成复盘”，停止。

3. 按四类归纳，每类 1 到 3 条，每条末尾标注来源日期（如 `11-15`）：

```text
公司工作
个人业务
个人学习
日常生活
```

没有内容的类别写“本月无相关记录”，不要凑数。

4. 把内容写入临时文件 `.tmp/review-YYYY-MM.md`，第一行固定为：

```text
【草稿】生成于 YYYY-MM-DD，待确认
```

5. 写入飞书：

```bash
python tools/feishu/feishu_client.py review --month 2026-11 --file .tmp/review-2026-11.md
```

6. 输出 `已写入 N 段` 表示成功；输出 `已有内容，未覆盖` 表示该月速览已存在，先问用户是否重写，得到明确同意后才加 `--force`。

7. 回读确认：

```bash
python tools/feishu/feishu_client.py month --month 2026-11
```

## 写作规则

- 只使用日志里出现的事实，不补数据、不推测影响、不编造成果。
- “推进”“计划”不能写成“完成”。
- 同类事项合并成一条，保留最能说明结果的那句。
- 记录少于 3 天时，开头加一句“本月记录较少，复盘覆盖可能不足”。
- 只写草稿，不标注“已确认”；确认由用户说了才算。

## 不能做

- 不修改、不删除原始日志条目。
- 不覆盖已有速览，除非用户明确同意。
- 不生成季度、半年、年度总结；这些留到后续版本。
- 不把账号、密钥、内部链接写进复盘。
