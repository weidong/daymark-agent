# 随手记录

把用户说的一件事，原样追加到当天日志下。

## 执行

在项目根目录运行：

```bash
python tools/feishu/feishu_client.py append "完成训练营第二期结营作业"
```

记录其他日期时加参数：

```bash
python tools/feishu/feishu_client.py append "评审月度复盘草稿" --date 2026-11-14
```

一次说了多件事，就分多次调用，一条一件事。

## 内容写法

- 用用户的原话，去掉“帮我记一下”“记录一条”这类请求语。
- 不加评价、不加推测，不补用户没说的时间、数字和成果。
- 默认不加“完成/推进/计划”标签；用户明确要求分类时才加。
- 保持一句话，不扩写成段落。

## 判断结果

- 输出包含 `已追加`：成功，回复日期和这条内容。
- 输出包含 `已存在相同内容，跳过`：说明已记过，不要重复写，直接告诉用户。
- 输出包含 `未找到「📅 行知日志」板块`、`读取块失败`、`刷新用户令牌失败`：失败，原样说明原因。
- 报 `tokens.json` 不存在或授权失效：提示先运行 `python tools/feishu/login.py`。

## 规则

1. 默认记到今天，按 Asia/Shanghai 计算。
2. 用户说“昨天”“上周五”或给出具体日期时，换算成 `YYYY-MM-DD` 再传 `--date`。
3. 当天还没开工也可以记录，工具会自动补齐日期标题。
4. 不写“开工”，那是 `daymark-start` 的职责。
5. 不修改、不删除已有条目；用户要求修改时先确认原句再操作。
6. 日期说不清、可能跨天时，先问一句，不要猜。
